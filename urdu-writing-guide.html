How to write and manage Urdu documents online

This guide explains a practical workflow for composing Urdu, formatting a document, using the included templates, and keeping a copy of your work.

In this guide 1. Start a document 2. Type Urdu with an English keyboard 3. Format right-to-left text 4. Adapt a template 5. Save, back up, and print 6. Use the editor tools 7. Troubleshoot common issues

1. Start a document

Choose Create a document to open a blank page, or select a template card for a letter, essay, or poem. The editor opens with the document name at the top and a writing page below the formatting ribbon. Rename the file before you begin so it is easy to find in your saved-files list.

2. Type Urdu with an English keyboard

Urdu keyboard mapping is on by default. Use the English keys shown below; the letter printed on your physical key produces the matching Urdu character in the chart. Hold Shift for entries marked “Shift +”. For example, M produces م and Shift+A produces آ.

Check or try an English key

Or click any key in the chart to see its Urdu character.

Urdu output appears here

Switch the Urdu toggle off to type English characters. The Urdu and symbol keys on the on-screen keyboard remain available, and you can paste Urdu text from another source into the editor.

3. Format right-to-left text

Use the editor’s ribbon to choose a Nastaliq or Naskh font, change text size, and apply bold, italic, underline, text color, or highlighting. Paragraph controls provide lists, alignment, spacing, and text direction. The Insert tab provides tables, pictures, page numbers, headers, footers, and emoji.

For a mixed Urdu and English paragraph, check the direction and alignment after pasting. Select the affected paragraph and apply the direction that makes its reading order clear. Preview the complete page before printing; line wrapping can change with fonts and paper settings.

4. Adapt a template

Template cards show a preview of the page content. The letter template contains a complete sample leave request; the essay and poetry cards contain complete sample writing. Select a card to open its text in the editor, then replace example names, dates, school details, and wording with your own accurate information.

Templates are examples, not official forms or legal advice. If an organization provides its own required format, use that format and verify every required detail before submission.

5. Save, back up, and print

  1. Autosave: The editor saves changes in this browser on this device. Saved files appear on the home page and can be reopened from their cards.
  2. Download a copy: Use the editor’s Download menu to export a PNG image or PDF. Choose all pages, the current page, or selected pages. Both formats include the Urdu Writer logo watermark. Store important exports somewhere separate from this browser.
  3. Save as PDF: Choose PDF in the Download menu, then select Save as PDF in the browser print dialog. Review page selection, margins, and Urdu font rendering in the print preview.
  4. Open a text file: On the home page, choose Open a TXT file. Confirm the text and line breaks after it loads.

Local browser storage is not cloud storage. Clearing site data, using private browsing, changing browsers, or using another device can make saved documents unavailable. Keep an exported backup of anything you cannot afford to lose.

6. Use the editor tools

The Layout tab controls page margins, orientation, paper size, columns, line numbers, page borders, and page color. Choose Preview to inspect the document before printing. Use Header and Footer on the Insert tab to edit text that repeats on printed pages.

Select a table cell to add or remove rows and columns, change cell color and text alignment, set borders, or adjust table width. Select an inserted picture to resize it, choose text wrapping, align it, or remove it. The View tab also provides ruler visibility, dark mode, and zoom.

Use Urdu → English to transliterate selected text or, with no selection, the full document into Roman Urdu. The Urdu typing toggle switches English-key Urdu typing on or off. Open the on-screen keyboard when you need Urdu, English, or symbol keys. Use Find to locate text and Replace to change matching text.

7. Troubleshoot common issues

An English key did not enter the Urdu letter I expected

Check that Urdu keyboard mapping is on, then use the interactive key chart above to confirm which Urdu character each English key produces. Switch the Urdu toggle off when you want to type English.

My saved file is missing

Check that you are using the same browser profile and device where you wrote it. If site data was cleared, the local copy may be gone. Open any TXT or Urdu Writer JSON backup you previously exported.

The printed page looks different

Review the browser print preview, page size, and margins. Confirm the correct Urdu font is available and let web fonts finish loading before printing. Adjust text size and page layout in the editor as needed.

This guide describes the current browser-based editor. Sign-in, cloud synchronization, and online feedback storage are not active until their backend services are configured.
